CARCA CLONE v2.0.1 — 盤面を広く、盤面上でタイルを回転

更新内容
・「新しい対局」で相手（2人／通常CPU／学習CPU）と強さ・学習した人を選択。
・開始後は相手設定欄を非表示。対局途中で誤って相手を変更しません。
・画面下の大きな「現在のタイル」・左右回転パネルを廃止。
・盤面の＋を押すとタイルを仮置き。仮置きタイルをタップすると右に90度回転。
・盤面内の↶・↷でも回転可能。「ここに置く」で確定、×で仮置きを取消。
・置けない向きは赤枠となり確定不可。＋はどれかの向きなら置けるマスを表示。
・盤面左下の小さいタイルをタップして、仮置きする前にも回転可能。
・1本指で盤面移動、2本指で拡大縮小、確定後のミープル配置は従来通り。
・保存キーと学習モデル形式は従来通り。v2.0.0の学習JSONを引き継げます。

GitHubへの反映
1. ZIPを展開します。
2. 0123porupoponnu/carca-clone の Code → Add file → Upload files を開きます。
3. ZIPの中身を同じ階層へアップロードし、同名ファイルを上書きしてCommitします。
   ZIPそのものや、フォルダで一段深くなった状態でアップロードしないでください。
4. index.html、rules.js、cpu.js、strong.js、learning.js、tile-master.json、images一式をまとめて更新してください。
5. GitHub Pagesの反映後に再読み込みし、画面上部のv2.0.1を確認します。
