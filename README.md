# CARCA CLONE — Phase 1 試作版

## 起動
`index.html`をブラウザで開きます。GitHub Pagesにこのファイルを置いても利用できます。

## 今動くもの
- タイルの回転と隣接辺の一致による配置判定
- 人間対簡易CPU
- 都市・道路・修道院へのミープル配置（簡易モデル）
- 完成時および終了時の都市・道路・修道院の得点（簡易モデル）
- BGAリプレイURLを端末内に控える欄（学習処理なし）

## 重要な制限
- **公式カルカソンヌを完全実装したものではありません。** タイル構成と枚数は試作用で、正式な72枚構成ではありません。
- 草原のミープル・草原得点、都市・道路内の独立した複数コンポーネント、紋章、路線の正確な交差点分割などは未実装です。
- この試作版の得点は、複雑な盤面では実際と異なる場合があります。
- BGAのURLからのデータ収集・リプレイ解析・本人の模倣学習は未実装です。
- タイル画像はCSS/SVGによるオリジナルの簡易図です。

## 本実装の推奨構造
- `src/engine/tiles.ts`: 実在の基本セット72枚を全種類・全向き・内部地形区分で定義
- `src/engine/rules.ts`: 合法手とミープル配置ルール
- `src/engine/scoring.ts`: 都市・道・修道院・草原の領域解析と採点
- `src/ai/baseline.ts`: 合法手を選ぶベースCPU
- `src/ai/clone.ts`: 学習済みプレイヤーの模倣スコアと温度付き選択
- `src/training/replay-schema.ts`: リプレイからの合法手候補・選択手の正規化
- `src/ui/`: iPad対応のゲーム画面

## 検証チェックリスト
1. 全72枚を正しい分布で投入し、開始タイルを1枚だけ設置
2. 辺の一致と内部連結を正しく判定
3. 接続済み地形の占有チェックと合流（相乗り）
4. 完成時とゲーム終了時の得点、同数ミープルによる複数者得点
5. 草原と完成都市の隣接関係を判定し3点/完成都市
6. CPUが全手を合法にプレイできること
7. リプレイで局面・手札・選択手を取得できる範囲を調べ、収集許諾を確認
8. 訓練データと評価データを試合単位で分け、本人の選択手top-1/top-3一致率を計測

## 注意
BGAへの自動アクセスや無許可のデータ収集は実装していません。リプレイURLを保存するだけです。
